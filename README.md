# penoplast — операційна система автономного бізнес-агента

Репозиторій — "пам'ять" AI-агента, який шукає та запускає прибуткові бізнес-моделі
для власника (Данія, стартовий бюджет 0 DKK).

## Структура
| Шлях | Призначення |
|---|---|
| `ops/STATE.md` | Поточний стан і точні інструкції для наступного запуску агента |
| `ops/JOURNAL.md` | Журнал роботи (гіпотези, дії, факти, результати) |
| `ops/LEDGER.md` | Фінансовий облік: лише підтверджені платежі та витрати |
| `ops/INVENTORY.md` | Доступні інструменти, акаунти, обмеження |
| `ops/OWNER_ACTIONS.md` | Короткий список дій, які потребують власника (з готовими рішеннями) |
| `research/` | Дослідження ринку з джерелами |
| `experiments/` | Картки експериментів (гіпотеза → дії → результат → висновок) |
| `products/` | Вихідний код і готові файли продуктів |

## Правила
1. Дохід = лише підтверджені надходження. Прогнози окремо.
2. Жодних витрат, публікацій чи повідомлень третім особам без дозволу власника.
3. Кожен звіт: VERIFIED / UNVERIFIED / ASSUMPTIONS / BLOCKERS / NEXT ACTION.
4. Якщо дані спростовують гіпотезу — зупинити експеримент і перейти до наступного.
